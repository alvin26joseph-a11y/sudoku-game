# Sudoku Game

An interactive, web-based Sudoku game built using modern HTML5, CSS3, and Vanilla JavaScript. Features real-time puzzle validation and a clean, responsive user interface.

Live Demo: [Play Sudoku Game](https://alvin26joseph-a11y.github.io/sudoku-game/)

---

## Features

- **Interactive 9x9 Grid**: Smooth grid interaction for inputting numbers and solving puzzles.
- **Real-Time Validation**: Instant input checking to highlight valid and conflicting numbers based on standard Sudoku rules.
- **Responsive Interface**: Optimized layout built with CSS3 for seamless play across desktop and mobile devices.
- **Zero External Dependencies**: Pure Vanilla JavaScript implementation without heavy frameworks.

---

## Tech Stack

- **Frontend**: HTML5, CSS3
- **Scripting**: JavaScript (ES6+)
- **Deployment**: GitHub Pages
